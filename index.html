GitHub 연결

하이라이트와 메모를 비공개 저장소에 저장해서 기기끼리 맞춥니다. 토큰은 이 기기 브라우저에만 저장되고 GitHub API 말고는 어디에도 보내지 않습니다.

토큰 만드는 법
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Resource owner: 본인 계정, Expiration: 원하는 기간
  3. Repository access: Only select repositories → 학습 내용이 있는 비공개 저장소 하나만 선택
  4. Permissions → Repository permissions → Contents: Read and write (나머지는 그대로)
  5. Generate token → 나온 값(github_pat_…)을 아래에 붙여넣기

공용 컴퓨터에서는 토큰을 저장하지 마세요. 같은 계정의 다른 GitHub Pages 사이트에 남이 만든 코드를 올리면 이 토큰이 노출될 수 있습니다.
